# Zorko

**Находит заведения, которым нужен сайт** — по открытым данным OpenStreetMap.

Zorko проходит город по карте, собирает кафе, барбершопы, автосервисы и другие заведения,
отбирает тех, у кого нет сайта, сам пробует найти сайт там, где карта о нём не знает,
проверяет найденные сайты на проблемы и готовит текст первого сообщения под каждое заведение.

Одна программа, один файл, никаких зависимостей кроме Python 3.8+. Окно открывается в браузере,
данные остаются на вашем компьютере.

**Попробовать без установки:** <https://whhhsww.github.io/zorko/app/> — версия для браузера,
работает и с телефона. В ней есть поиск по карте, приоритет, тексты и выгрузка, но нет проверки
сайтов и поиска аккаунтов в Instagram: браузер не даёт странице открывать чужие сайты.
Эти проверки есть только в версии для компьютера.

*A desktop tool that finds local businesses without a website, using OpenStreetMap data.
Interface and generated texts are in Russian and Ukrainian.*

---

## Запуск

```bash
python zorko.py
```

На Windows можно двойным щелчком по `start_zorko.bat`.

Откроется окно программы в браузере: <http://127.0.0.1:8765>
Чёрное окно консоли закрывать нельзя — в нём работает сама программа.

Сторонние пакеты не нужны: только стандартная библиотека Python.

## Как пользоваться

1. Отметьте категории, впишите город (можно несколько через запятую) и нажмите **«Найти заведения»**.
   Zorko просит у сервера карт сразу весь город одним запросом и делит его на части, только если
   запрос не прошёл.
2. Нажмите **«Искать и проверять сайты»**. Самая долгая часть: идёт в 8 потоков, останавливается в любой момент.
3. Нажмите на строку заведения — соберётся текст под него: короткий для мессенджера, письмо на почту
   и план разговора по телефону. Рядом кнопки Instagram, Telegram, Viber, WhatsApp, «Позвонить».
4. **«Сохранить в CSV»** выгружает то, что отобрано фильтрами, в файл рядом с программой.

## Как Zorko понимает, есть ли у заведения сайт

В OpenStreetMap адрес сайта указан далеко не у всех, даже когда сайт существует. Поэтому Zorko
ищет его сам, от дешёвого к дорогому:

| Способ | Что делает |
| --- | --- |
| Теги карты | `website`, `contact:website`, `url`, `operator:website` и соседние |
| Домен из почты | `info@zerno-cafe.com` значит сайт `zerno-cafe.com` (бесплатные почты пропускаются) |
| Такое же название | если у заведения с тем же названием сайт уже известен, он и тут тот же |
| Wikidata | официальный сайт из свойства P856 |
| Подбор домена | из названия латиницей, с проверкой, что на странице встречается название или телефон |
| Instagram | подбор имени аккаунта по названию и городу, с проверкой имени на профиле |

Найденный сайт проверяется: не открывается, нет HTTPS, нет мобильной версии, собран на конструкторе,
домен без страницы, старый год в подвале.

**Чего Zorko не умеет:** читать ссылку на сайт из описания профиля Instagram. Instagram отдаёт
описание только живому браузеру, программе — нет. Поэтому аккаунт Zorko находит и даёт ссылку,
а в описание вы заглядываете сами; нашли сайт — кнопка «У них есть сайт» уберёт заведение из списка.

## Что ещё внутри

- приоритет 0–100: выше те, кому сайт нужнее и с кем есть как связаться;
- статусы (новый, написал, ответил, отказ) и заметки, которые переживают повторный поиск;
- дубли одного заведения и сети прячутся сами;
- фильтры по городу, категории, контактам, состоянию сайта; сортировки; выгрузка в CSV;
- кнопка «Проверить связь»: показывает, какие серверы карт отвечают.

## Ограничения, о которых честно

- **Серверы карт бесплатные и общие.** После большого поиска они могут временно перестать отвечать
  вашему адресу; VPN делает это вероятнее. Zorko это замечает и пишет об этом, а не висит молча.
- **Покрытие OpenStreetMap неровное.** В больших городах оно хорошее, в маленьких части заведений
  на карте просто нет.
- **«Сайт не нашёлся» — не доказательство, что сайта нет.** У каждой строки есть кнопка
  «Найти в Google» для проверки руками.
- **Instagram** может закрыть доступ программе в любой момент; это не поломка Zorko.
- Zorko **ничего никому не отправляет сам**: письма и сообщения пишете и отправляете вы.
