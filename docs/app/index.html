Это версия для браузера: ничего не устанавливать, работает с телефона, данные хранятся в этом браузере. Чего она не умеет: открывать чужие сайты и профили, поэтому проверки «есть ли сайт на самом деле», разбора проблем сайта и поиска аккаунтов в Instagram тут нет — браузер запрещает страницам читать чужие сайты. Эти проверки есть в версии для компьютера.

Отметьте категории, впишите город и нажмите «Найти заведения».
