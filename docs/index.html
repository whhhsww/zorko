Парсер заведений · данные OpenStreetMap

Кафе без сайта ждут вашего письма. Zorko покажет, где они.

Проходит город квадрат за квадратом, находит заведения без сайта и со слабым сайтом и расставляет их по приоритету. Писать первым остаётся вам.

От пустой карты до первого сообщения

  1. шаг 1

    Выбираете город и нишу

    Кафе, барбершопы, автосервисы, стоматологии: подойдёт любая категория, которая есть на карте.

  2. шаг 2

    Парсер проходит город квадратами

    Каждый квадрат запрашивается отдельно, поэтому окраины не теряются, а повторы отсеиваются.

  3. шаг 3

    Остаются те, кому нужен сайт

    Заведения без сайта и заведения, у чьих сайтов нашлись проблемы.

  4. шаг 4

    Вы пишете первым

    С контактом из карточки и готовым черновиком сообщения.

Что умеет Zorko

Бесплатный источник

Данные берутся из OpenStreetMap. Ключи API и оплата за каждый запрос не нужны.

Проверка сайта

Нет HTTPS, нет мобильной версии, сайт собран на конструкторе, в подвале старый год.

Приоритет

Наверху списка те, у кого сайта нет совсем, а телефон или мессенджер указан.

Статусы

Новый, написал, ответил, отказ. Сразу видно, с кем вы уже говорили.

Черновик сообщения

Первое сообщение опирается на настоящую проблему заведения. Отправляете его вы сами.

Выгрузка

Список сохраняется в CSV и открывается в Excel или Google Таблицах.

Как начать

В браузере

Ничего не устанавливать, работает и с телефона. Поиск по карте, приоритет, готовые тексты, выгрузка в CSV. Данные хранятся в вашем браузере.

Чего нет: проверки сайтов и поиска аккаунтов в Instagram — браузер не даёт странице открывать чужие сайты.

Открыть Zorko

На компьютере

Один файл на Python, без зависимостей. Умеет всё: сам ищет сайты по домену из почты, Wikidata и подбору адреса, проверяет их на проблемы и находит аккаунты в Instagram.

Скачайте с GitHub и запустите python zorko.py. Окно откроется в браузере.

Скачать с GitHub

Zorko бесплатный, исходный код открыт по лицензии MIT. Сообщения заведениям отправляете вы сами.

Частые вопросы

Откуда берутся заведения?

Из OpenStreetMap, открытой карты, которую ведут добровольцы. В больших городах покрытие хорошее, в маленьких части заведений на карте может не быть.

Какие данные собирает парсер?

Только открытые сведения о бизнесе: название, категорию, адрес, телефон, сайт и часы работы. Личные данные людей он не собирает.

Сообщения уходят автоматически?

Нет. Zorko готовит черновик, а отправляете вы сами из своего мессенджера или почты.

Нужен ли ключ Google?

Нет. Поиск работает без платных API.
